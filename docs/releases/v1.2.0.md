# Crimson Desert Telemetry v1.2.0

This release adds optional, read-only nearby engine-light telemetry and restores
exact support after the latest Crimson Desert update.

## Highlights

- Adds the disabled-by-default `[Lights]` module and additive snapshot schema 1.2.
- Reports verified engine-light position, point/spot kind when known, linear color,
  record/renderer flags, and conditional renderer scale/final linear RGB.
- Does not claim physical range, lumens, generic enabled state, fire/effect lights,
  direction, or durable source identities.
- Adds exact, live-validated support for Steam build `25116796`, EXE `1.0.0.2760`.
- Keeps schema 1.1 and all existing player/camera behavior unchanged when lights
  are disabled.

The package requires an x64 ASI loader and the Microsoft .NET 8 ASP.NET Core
Runtime (x64). The in-game HUD and light module both remain disabled by default.
