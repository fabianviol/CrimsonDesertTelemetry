# Crimson Desert Telemetry 2.1.14

- Adds exact Windows/Steam support for **Crimson Desert patch 2.03.02**. Technical identity: EXE file version `1.0.0.2976`, Steam build ID `25477059`; unknown executables still fail closed.
- Restores player/render-camera telemetry, live rendered-light contributions, smoothed local lights, ambient/sky data, HUD/radar, fullscreen markers, and local HTTP/WebSocket feeds on that patch.
- Corrects Windows standard-handle inheritance when starting the .NET host. This addresses a real bootstrap defect that could plausibly cause Win32 error 6; the specific Nexus user report remains unconfirmed without its log.
- Retains the per-light geometric visibility experiment but ships it **off by default** because it can falsely label lights behind solid geometry as visible. F11/occlusion hiding is experimental and only meaningful when that setting is enabled.
- Keeps the 2.1.11 DXGI swapchain-lifetime correction. No NVIDIA/DLSS runtime dependency was added.

Known limitations and test scope:

- Global sky RGB, player/camera, rendered lights, smoothed lights, HUD and HTTP/WebSocket feeds worked in a clean live load of the exact 2.1.14 ZIP on patch 2.03.02. Camera-local sky visibility did **not** publish in that session, so the derived local ambient RGB was unavailable. These fields remain optional; do not use them as a guaranteed input.
- One earlier load with this ZIP ended in `DXGI_ERROR_DEVICE_HUNG`. A clean deployment of the same ZIP subsequently loaded and ran. The cause of the earlier GPU hang is not established. If it recurs, disable the ASI and include the game crash record plus Telemetry logs in a report.
- Per-light geometric visibility is experimental and disabled in the supplied INI; it is not a reliable occlusion filter.
