# 2.1.10 — stable working-feature release

This `CDT_RESEARCH=OFF` release updates the old public 2.0.2 package with the
validated working telemetry path: authored/raw/EMA renderer lights, player and
render camera, ambient, HUD/3D radar, fullscreen markers, notifications and
configurable F8–F10 controls. Every offered boolean setting is enabled in the
supplied production INI. F11 and unfinished per-light visibility/hiding controls
are excluded; original light records and RGB values remain available unchanged.

Native light and sky capture now wait for the host's first valid player/render-
camera `playing` state. This prevents the initial menu or a cold shader rebuild
after a graphics-driver update from consuming a GPU transaction. Command-list
submission has a separate 60-second bound; a submitted GPU fence retains its
strict 5-second bound and now logs the exact timeout stage.

DMM2.8.1 clean deployment was verified, but its remove/upgrade path can leave
both Telemetry DLLs and both lowercase CFG files in the game directory. With the
game closed, remove the old package, delete only those four Telemetry leftovers,
then import this ZIP. Do not delete the ASI loader. The package README lists the
exact filenames.

The project goal remains reliable local ambient/sky occlusion plus geometric
visibility for every relevant light, including off-screen and behind-camera
sources. The current blocker is consistent occlusion across fires, candles,
lamps, walls, buildings and terrain. Ambient passed open/enclosed/open, while its
camera-orientation semantics and per-light geometry still require work. The full
current state and preserved research are on GitHub; forks and contributions are
welcome.

Automated validation:70/70 managed controls and27/27 selected native production
controls pass, including the actual named playable-world event, D3D12 capture,
all UI owners together, SDR/scRGB, package profile and exact ZIP equality. The two
known research readback failures remain excluded and are not linked into OFF.
Final live acceptance passed with all six deployed files exact, every supported
production feature enabled, live HTTP and WebSocket feeds, and successful
F8/F9/F10 off/on toggles.
See [stable release validation](../STABLE_RELEASE_VALIDATION.md) for live evidence,
hashes, VirusTotal results and stated hardware limits.

The external Nexus2.0.2 graphics crash remains unresolved because the reporter's
GPU/driver, other overlays and faulting module/offset are unavailable. This
release is not presented as a confirmed fix for that separate system.
