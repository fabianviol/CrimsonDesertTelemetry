# Crimson Desert Telemetry v1.0.0

A standalone community telemetry layer for Crimson Desert. Build lighting integrations,
overlays and other tools using a shared local API, without rediscovering the camera
and player data yourself.

## Included

- Player world position and physics-root orientation (forward/up vectors and heading).
- Native render-camera position, basis, vertical FOV, aspect ratio and near plane.
- Local HTTP snapshots, health/schema endpoints and a WebSocket stream; JSON Lines
  is also available through the command-line host.
- Configurable shared sampling from 1 to 240 Hz (default 60 Hz; not a hard real-time guarantee).
- ASI startup and an optional English Dear ImGui HUD, **disabled by default**.

The camera reader no longer relies on DLSS/Streamline camera copies. Upscaling-off
cold starts and camera changes have been tested on the development NVIDIA setup.
The existing HTTP v1 endpoints and JSON schema 1.1 remain unchanged.

For developers: [API reference](https://github.com/fabianviol/CrimsonDesertTelemetry/blob/main/docs/API.md)
and [Python/JavaScript examples](https://github.com/fabianviol/CrimsonDesertTelemetry/tree/main/examples).

## Installation

Close the game, import the **ModManagers.zip** package, then enable/deploy the ASI
using your mod manager. An ASI loader and the **.NET 8 ASP.NET Core Runtime (x64)**
are required. Keep the companion files together; do not rename the `.cfg` metadata.

After launch, connect to `http://127.0.0.1:27311/v1/health` or
`ws://127.0.0.1:27311/v1/stream`. To enable the HUD, set `[Overlay] Enabled=1` in
`CrimsonDesertTelemetry.ini` and restart. F8 toggles visibility; F9 toggles details.
An older customized INI may retain `Enabled=1` instead of the new disabled default.

When upgrading, replace both `.cfg` companions with the new package versions;
only the INI contains user settings. A local DMM upgrade retained old `.cfg`
metadata in the game directory even after deploying the new DLLs.

## Supported scope and limitations

- Steam build **24994088**, executable **1.0.0.2658**. Unknown builds are rejected.
- DMM has been used in local testing; full JSON Mod Manager lifecycle validation is pending.
- AMD/Intel GPU hardware is not yet tested. The optional HUD supports D3D12 / 8-bit SDR;
  HDR, frame generation and NVIDIA recording remain unverified.
- Player orientation describes the physics root, not the animated body pose.
- `farPlane` is unknown/null. Light-source telemetry is not included in this release.
- Sampling timestamps are not engine-frame timestamps; reads do not guarantee engine-frame atomicity.
- Close the game before replacing/removing the ASI. Hot-unload is unsupported.
