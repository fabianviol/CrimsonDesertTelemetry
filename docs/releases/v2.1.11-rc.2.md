# 2.1.11-rc.2 — Streamline swapchain compatibility candidate

This private `CDT_RESEARCH=OFF` candidate addresses the two current Nexus crash
reports without adding or restoring research functionality.

Both reports use NVIDIA driver 616.92 and show Streamline DLSS/DLSS-RR failing to
associate the game's newly created swapchain with its command queue:

```text
linkSwapchainToCmdQueue: Failed to create swap chain - Access is denied.
CreateSwapChainForHwnd failed: 0x80070005 (E_ACCESSDENIED)
```

The overlay's DXGI factory callback previously patched Present, Present1, Resize
and SetColorSpace on the new swapchain before returning through Streamline's outer
factory wrapper. It now retains the returned COM references and lets the existing
overlay worker install those hooks 500 ms later. Telemetry behavior and the HUD
renderer are otherwise unchanged.

Validation completed before live use:

- release `CDT_RESEARCH=OFF` ASI build
- managed solution tests
- production package expanded/ZIP/self-test
- all eight D3D12 graphics smoke modes covering HUD, status notifications and
  light markers in SDR and scRGB
- complete native 30-test suite
