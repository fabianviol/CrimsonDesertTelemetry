# Crimson Desert Telemetry v1.1.0

This release adds fail-closed automatic compatibility for new Crimson Desert
executables while preserving exact identification for manually tested builds.

## Highlights

- Unknown EXE hashes are accepted only when the complete player/camera layout is
  relocated uniquely through guarded code references, writable globals, player
  RTTI and multi-slot camera/context table fingerprints.
- Health now distinguishes exact `tested` builds from `automatic` compatibility
  and reports the actual executable identity plus reference layout.
- Adds the offline `check-compatibility <exe>` diagnostic.
- Adds exact support for Steam build `25050808`, EXE `1.0.0.2692`. It was first
  recognized automatically, then validated live with independent camera and player
  movement at roughly 60 samples/second and no telemetry errors.
- Keeps the HTTP/WebSocket v1 endpoints and snapshot JSON schema 1.1 unchanged.

The package still requires an x64 ASI loader and the Microsoft .NET 8 ASP.NET Core
Runtime (x64). The in-game HUD remains disabled by default.
