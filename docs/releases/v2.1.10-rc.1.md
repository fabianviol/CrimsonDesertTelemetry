# 2.1.10-rc.1 — stability candidate

Not yet published. This production candidate keeps raw/smoothed light telemetry,
player/render camera, ambient, HUD/radar, fullscreen markers and notifications.
The supplied INI enables all offered features and diagnostics.

- Exclude unfinished per-light geometric visibility and its HideOccluded/F11
  controls after failed live concealed-source tests. Markers include lights behind
  geometry. Preserve original API records/RGB; visibility metadata is disabled.
- Keep all research and occlusion evidence for later development. Old diagnostic
  INIs cannot activate excluded features in the OFF build.
- Offer 31 production settings. F8–F10 each support remapping or disabling with0.
- Refresh package/configuration/API descriptions and retain all runtime companions.

native tests including combined UI SDR/scRGB, ON preservation build/model, exact
ZIP validation and isolated packaged-host bootstrap pass. Two existing research
readback failures are excluded from this release run, not claimed fixed.

[validation record](../STABLE_RELEASE_VALIDATION.md).
